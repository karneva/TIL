# 자료구조와 알고리즘

## 1. 자료구조

- 데이터를 저장, 조직, 관리하는 방식
- 배열, 연결 리스트, 스택, 큐, 트리, 그래프 등
- 각 자료구조는 데이터의 접근, 삽입, 삭제 등에 있어서 고유한 성능 특성을 가지고 있음

## 2. 알고리즘

- 특정 문제를 해결하기 위한 명확한 절차나 방법론
- 정렬, 탐색, 최단 경로 찾기, 동적 프로그래밍 등
- 문제 상황에 따라 적합한 알고리즘을 선택

## **3. 자료구조와 알고리즘의 관계**

1. 상호 보완적 역할
    - **자료구조**는 데이터를 효율적으로 다룰 수 있는 기반을 마련
    - **알고리즘**은 이 자료구조를 활용하여 문제를 해결하는 방법을 제공
2. 문제 해결
    - 복잡한 문제를 해결하기 위해서는 데이터를 어떻게 저장하고 관리할 것인지(자료구조)와 
    그 데이터를 이용해 문제를 어떻게 풀 것인지(알고리즘)를 함께 고려

## 4. 정리

- **자료구조**는 데이터를 어떻게 저장하고 조직할 것인가를 결정
- **알고리즘**은 그 데이터를 활용해 문제를 어떻게 효율적으로 해결할 것인가
